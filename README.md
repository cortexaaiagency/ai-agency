# Cortexa - Grounded AI for document to campaign

Live: cortexa.kleap.io | Built by 14yo in Bangalore 🇮🇳

### Why?
ChatGPT makes up features. Marketing teams waste hours fixing it.

Cortexa = Upload docs → Ask → Get brand-safe copy with citations → Push to HubSpot/Mailchimp

### What works now
- [x] PDF ingestion
- [x] Grounded retrieval with citations
- [x] Campaign draft generation
- [ ] Notion / S3 / Drive connectors
- [ ] Brand voice controls
